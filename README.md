🎨 Aplicación Web: Selector de Color RGB Avanzado
📋 Descripción de la Actividad
Desarrollo de una interfaz web interactiva orientada a la programación de interfaces web, diseñada para la manipulación y conversión en tiempo real de espacios de color utilizando notación decimal RGB y códigos hexadecimales.

🚀 Características Principales
Controles Duales (Sliders e Inputs Numéricos): Permite ajustar de forma continua o ingresar de manera exacta los valores de los canales Rojo ®, Verde (G) y Azul (B) en el rango de 
[
0
,
255
]
[0,255].
Selector de Color Nativo (Color Picker): Integración con la paleta de colores nativa del sistema para la selección visual directa.
Actualización en Tiempo Real: Sincronización bidireccional instantánea entre los controles deslizantes, campos numéricos y el renderizado visual.
Diseño Moderno y Responsivo: Maquetación desarrollada con Bootstrap 5, incorporando efectos visuales, gradientes y tipografías optimizadas para evitar la fatiga visual.
🛠️ Tecnologías Utilizadas
HTML5: Estructuración semántica de la interfaz.
CSS3 & Bootstrap 5: Estilos personalizados, gradientes y diseño adaptativo.
JavaScript (ES6): Manipulación del DOM, eventos de escucha (input), control de rangos y conversión algorítmica de bases numéricas (Decimal a Hexadecimal y viceversa).
